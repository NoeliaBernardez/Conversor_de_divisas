
Conversor de Divisas (Cotización en Vivo)

Aplicación de consola desarrollada en Python que consume la API pública de [DolarApi](https://dolarapi.com) para consultar cotizaciones en tiempo real e ingresar un monto en Pesos Argentinos (ARS) para convertirlo a Dólar Oficial y Dólar Blue.

## Características

- Consulta en vivo las cotizaciones mediante peticiones HTTP.
- Muestra los valores de Compra, Venta y la Conversión final en una tabla formateada.
- Manejo robusto de errores (errores de conexión, respuesta de API, entradas no numéricas, datos corruptos).
- Código adaptado a estándar **PEP 8**, anotaciones de tipos (*Type Annotations*) y documentación mediante **Docstrings PEP 257**.

---

## Requisitos Previos
